# 全局管理员

全局管理员按 QQ 号识别，可在机器人所在的任何群使用要求管理员权限的命令。部署者在 `config/admins.toml` 维护名单；群主与群管理继续使用 QQ 群角色授权。

## 权限关系

- 要求“管理员及以上”的群聊命令对全局管理员开放，例如唤醒开关、日报、总结、词云、规则管理和牛牛文案模式。
- 同一用户具有群管理和全局管理员身份时，按全局管理员处理。
- 群聊管理命令在群内发起；私聊功能按各自命令的权限规则执行。

## 配置

编辑 `config/admins.toml`（首次使用从 `config/admins.toml.example` 复制）：

```toml
global_admins = [
    "1000000000",
]
```

- 条目为 QQ 号数字字符串；非法条目会被跳过并在日志中告警。
- 修改后约 5 秒内热重载生效，无需重启。
- 文件缺失或列表为空时，全局管理员名单为空，群角色授权照常生效。
- 文件损坏或格式错误时保留上次有效名单，修复文件即可恢复。

## 审计

应用日志中的 `ADMIN_TRACE` 行记录两类事件，便于回溯：

- `registry_loaded`：注册表加载或热重载生效，含当前名单。
- `global_admin_unlock`：管理员门禁检查中，全局管理员身份提供授权时（群角色本就足够时不会记录）。

## 与 NoneBot 超用户的关系

QuickQuip 的全局管理员唯一配置来源是 `config/admins.toml`。NoneBot 的 `SUPERUSERS` 设置对这些管理命令的授权无效，请在管理员名单中填写 QQ 号。

注册表与统一角色解析的选择依据见 [ADR-0010](../dev/adr/0010-global-admin-registry.md)。
