# QuickQuip 群内游戏指南

本指南中的冷却时间、超时与金币数额均为默认值，部署者可在 `config/games.toml` 中调整。

---

## 快速入口

| 想玩什么 | 一句话上手 |
|----------|-----------|
| 数字炸弹 | `/game start 数字炸弹` — 猜 1-1000 的数字 |
| 21 点 | `/game start 21点 200` — 跟庄家比谁更接近 21 |
| 俄罗斯轮盘 | `/game start 俄罗斯轮盘 200` — 1v1 左轮对决 |
| 牛牛大作战 | `注册牛牛` — 养牛、击剑、打胶、冲排行 |
| 金币系统 | `/签到` `/金币` `/金币排行` |

通用命令：`/game list` 查看可玩游戏，`/game stop` 结束当前游戏，`/game score <游戏名>` 查看游戏排行。

---

## 1. 金币经济系统

所有对战类游戏共用一套金币系统。

| 命令 | 别名 | 说明 |
|------|------|------|
| `/sign` | `/签到` | 每日签到，+10 金币起步，连续签到递增（最高 +40/天） |
| `/gold` | `/金币` `/我的` | 查看金币余额、好感度、连续签到天数 |
| `/gold_rank` | `/金币排行` | 本群金币排行 TOP 10 |

金币可以在 21 点、俄罗斯轮盘、牛牛注销中使用。

## 2. 数字炸弹

纯猜数，不涉及金币。

```
/game start 数字炸弹
```

机器人从 1-1000 中随机选一个数字。大家在群里发数字猜：
- 猜小 → 机器人回复“小了，范围 X-1000”
- 猜大 → 机器人回复“大了，范围 1-X”
- 猜中 → 炸了！范围逐次缩小，60s 无操作自动结束。

| 命令 | 说明 |
|------|------|
| `/game start 数字炸弹` | 开始游戏（别名：`bomb`、`number_bomb`） |
| `/game stop` | 强制结束（会揭示答案） |
| `/game score 数字炸弹` | 本群猜中次数排行 |

游戏进行中时，发到群里的纯数字会被当作猜测。无关消息正常发送。

## 3. 21 点（Blackjack）

庄闲对战，金币下注，Bot 坐庄，硬 17 停牌。游戏名可用别名 `blackjack`、`bj`、`21`。

```
/game start 21点 200          ← 发起游戏，下注 200
入场 150                        ← 其他人加入（最低为发起者的一半）
入场 100
开局                            ← 发牌（每人 2 张 + 庄家 1 明 1 暗）
拿牌                            ← 要牌
停牌                            ← 停牌
结束 / 结算                     ← 手动结算（或全员停牌自动结算）
```

### 规则

| 规则 | 说明 |
|------|------|
| 人数 | 1-8 人 |
| 赌注 | 最低 20，其他玩家需 ≥ 发起者的 1/2 |
| Blackjack | 起手 2 张 21 点，庄家非 BJ 时 1.5 倍赔付 |
| 爆牌 | >21 点自动停牌，输掉赌注 |
| 平局 | 退还本金 |
| 庄家爆牌 | 所有未爆牌玩家 1:1 胜出 |
| 超时 | 90s 无操作自动结算 |

### 牌面符号

♠ 黑桃、♥ 红心、♦ 方块、♣ 梅花；A=1 或 11，J/Q/K=10，2-10 为面值。

## 4. 俄罗斯轮盘

1v1 左轮对决，金币下注，7 槽弹仓，1-6 颗子弹。游戏名可用别名 `russian`、`轮盘`、`rr`。

```
/game start 俄罗斯轮盘 200     ← 发起对决，赌注 200
3                               ← 装填 3 颗子弹
接受对决                         ← 对手加入（双方各扣 200）
开枪                             ← 轮流扣扳机
```

### 规则

| 规则 | 说明 |
|------|------|
| 人数 | 2 人 |
| 弹仓 | 7 槽，子弹随机排列 |
| 开枪顺序 | 装弹者先开枪，之后轮流 |
| 赌注 | 双方等额，赢者通吃 |
| 超时 | 30s 无操作自动结算（判超时者负） |
| 取消 | `/game stop` 全额退还双方 |

存活概率每枪后实时更新（如“下一枪存活概率：50.0%”）。

## 5. 牛牛大作战

持久化养成 RPG：牛牛永久存在，长度跨群共享。

### 5.1 入门

| 命令 | 说明 |
|------|------|
| `注册牛牛` | 创建你的牛牛，随机初始长度 |
| `注销牛牛` | 删除牛牛（花费 500 金币） |

注册后你获得一个随机长度（可为负数，负数 = 深度/女孩子状态）。

### 5.2 日常操作

| 命令 | 说明 |
|------|------|
| `打胶` | 对自己的牛牛进行操作，结果随机（CD 180s） |
| `击剑 @某人` | 和对方对战，影响双方长度（CD 180s；别名 `jj`/`JJ`/`Jj`/`jJ`） |
| `打胶运势` | 查看今日打胶运势值及评价 |
| `击剑运势` | 查看今日击剑运势值及评价 |
| `我的牛牛` | 查看当前长度、排名、双运势、评价、最后打胶时间 |
| `我的牛牛战绩 [N]` | 查看最近操作记录（默认 10 条） |

### 5.3 排行

牛牛提供四种排行视角：

| 命令 | 说明 |
|------|------|
| `牛牛总排行 [N]` | 自然数值排行（有符号排序，正数在前负数在后） |
| `牛牛绝对值排行 [N]` | 绝对值排行（最长和最深都能排前列） |
| `牛牛长度排行 [N]` | 正数群体排行（仅 length > 0 的用户） |
| `牛牛深度排行 [N]` | 负数群体排行（仅 length < 0 的用户） |
| `牛牛长度总排行 [N]` | 全局正数排行（跨群） |
| `牛牛深度总排行 [N]` | 全局负数排行（跨群） |
| `牛牛绝对值总排行 [N]` | 全局绝对值排行（跨群） |

默认显示前 10 名，可指定 N（最大 50）。`我的牛牛` 显示的排名因长度正负而异：正数用户只显示总榜名次；负数用户同时显示总榜、深度榜和绝对值榜 3 个名次。长度榜名次不在 `我的牛牛` 中显示。

### 5.4 长度区间与评价

| 长度 | 评价 | 角色 |
|------|------|------|
| >1000 | 牛牛之神 | — |
| 100~1000 | 牛牛之王 | — |
| 50~100 | 惊世骇俗！ | **牛头人** |
| 25~50 | 已经突破天际了嘛 | — |
| 10~25 | 已经很长了呢 | — |
| 0~10 | 细狗 / 蚕宝宝 | — |
| 0~-10 | 加油加油！我看好你哦 | — |
| -10~-25 | 你已经是一名女孩子了呢 | — |
| -25~-50 | 这名女生身体很健康 | — |
| -50~-100 | WOW，真的凹进去了好多呢 | **魅魔** |
| -100~-1000 | 哇哦！进化成魅魔了 | — |
| <-1000 | 深渊魅魔之神 | — |

> **牛头人**（length ≥ 50）和 **魅魔**（length ≤ -50）在击剑中有专属特殊效果，见 5.6 节。

### 5.5 打胶机制

打胶时会随机触发 11 种事件之一。打胶结果受**打胶运势**乘算影响——运势 > 1 放大变化，运势 < 1 缩水。

| 事件 | 说明 |
|------|------|
| 普通 | 长度正常增减，变化量正比于当前绝对值 |
| 🍀 幸运日 | 运势极佳，大幅增长 |
| 🌈 祝福 | 牛牛之神降临，暴增 |
| 🧘 贤者模式 | 平静稳定地增长 |
| 💥 狂暴 | 肾上腺素飙升，猛涨 |
| ✨ 特殊加成 | 神秘力量加持 |
| 🪞 镜像 | 长度正负反转（不受运势影响） |
| 🎰 赌徒 | 豪赌一把——可能暴增也可能暴跌 |
| 👻 噩梦 | 做噩梦吓缩了 |
| 萎缩 | 换蛋期打胶，长度减半 |
| 🚔 被抓 | 被人发现报警，关小黑屋（不受运势影响） |

打胶运势每日自动重掷，分布为对数对称：中位数=1，约 68% 在 [0.1, 10]，极端值可能达 1e-9 或 1e9。

**长度衰减**：当 \|长度\| 超过 50 后，每次打胶/击剑会按衰减率向 0 小幅回归——正侧默认 1%（`decay_rate_high`）、负侧减半为 0.5%，防止数值无限膨胀；\|长度\| ≤ 50 区间使用更慢的 `decay_rate_normal`（默认 0.5%）。这是纯粹的几何衰减，没有 50% 抑制之类的硬性上限。

### 5.6 击剑机制

击剑时有 8 种随机事件，其中两种为角色限定：

| 事件 | 说明 |
|------|------|
| 普通 | 正常伤害 |
| 💥 暴击 | 大倍率伤害 |
| 🔪 擦边 | 小倍率伤害 |
| 🔄 翻盘 | 弱者反杀（胜者翻转） |
| 👹 牛头人支配 | **牛头人专属**（length ≥ 50），40% 概率触发腰斩 |
| 👁 魅魔吞噬 | **魅魔专属**（length ≤ -50），窃取对手长度转移给自己 |
| 🪫 滑倒 | 攻击者自伤 |
| 🤝 平局 | 双方小幅减少 |

- 牛头人/魅魔事件仅在**胜者拥有对应角色**时激活，否则降级为普通事件
- 攻击或防守均可触发——牛头人/魅魔作为被击方获胜同样激活特殊效果
- 击剑运势影响胜率：运势 > 1 提升，运势 < 1 降低
- 胜率基于双方长度比值计算（差距越大，随机性越趋于 50/50）
- 胜者从败者身上夺取长度
- 被击剑者有 300s 保护期，期间不可再次被击
- 对未注册用户击剑会触发拒绝/强制注册/自伤事件
- 对机器人击剑会生成幻影牛牛（随机长度，不持久化）

### 5.7 文案模式切换

牛牛大作战支持多套文案预设，管理员可按群切换：

| 命令 | 说明 |
|------|------|
| `/牛牛文案` | 查看当前群的文案模式和可用模式列表 |
| `/牛牛文案 <模式名>` | 切换本群文案模式（仅群管理员） |

内置模式：

| 模式 | 说明 |
|------|------|
| `default` | 原版文案（默认），包含“打胶”“击剑”等措辞 |
| `safe` | 和谐版文案，事件描述和长度评价调整为更中性的表达 |

切换后立即生效，所有牛牛事件消息、长度评价、运势提示、CD 提示均使用对应的文案预设。
