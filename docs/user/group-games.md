# QuickQuip 群内游戏指南

这是一份给群友看的游戏玩法详解。

---

## 快速入口

| 想玩什么 | 一句话上手 |
|----------|-----------|
| 数字炸弹 | `/game start 数字炸弹` — 猜 1-1000 的数字 |
| 21 点 | `/game start 21点 200` — 跟庄家比谁更接近 21 |
| 俄罗斯轮盘 | `/game start 俄罗斯轮盘 200` — 1v1 左轮对决 |
| 牛牛大作战 | `注册牛牛` — 养牛、击剑、打胶、冲排行 |
| 金币系统 | `/签到` `/金币` `/金币排行` |

## 1. 金币经济系统

所有对战类游戏共用一套金币系统。

| 命令 | 别名 | 说明 |
|------|------|------|
| `/sign` | `/签到` | 每日签到，+10 金币起步，连续签到递增（最高 +40/天） |
| `/gold` | `/金币` `/我的` | 查看金币余额、好感度、连续签到天数 |
| `/gold_rank` | `/金币排行` | 本群金币排行 TOP 10 |

金币可以在 21 点、俄罗斯轮盘、牛牛注销中使用。后续更多游戏会接入金币下注。

## 2. 数字炸弹

**纯猜数，不涉及金币。**

```
/game start 数字炸弹
```

机器人从 1-1000 中随机选一个数字。大家在群里发数字猜：
- 猜小 → 机器人回复"小了，范围 X-1000"
- 猜大 → 机器人回复"大了，范围 1-X"
- 猜中 → 炸了！范围逐次缩小，60s 无操作自动结束。

| 命令 | 说明 |
|------|------|
| `/game start 数字炸弹` | 开始游戏（别名：`bomb`） |
| `/game stop` | 强制结束（会揭示答案） |
| `/game score 数字炸弹` | 本群猜中次数排行 |

游戏进行中时，发到群里的纯数字会被当作猜测。无关消息正常发送。

## 3. 21 点（Blackjack）

**庄闲对战，金币下注。Bot 坐庄，硬 17 停牌。**

```
/game start 21点 200          ← 发起游戏，下注 200
入场 150                        ← 其他人加入（最低为发起者的一半）
入场 100
开局                            ← 发牌（每人 2 张 + 庄家 1 明 1 暗）
拿牌                            ← 要牌
停牌                            ← 停牌
结束 / 结算                     ← 手动结算（或全员停牌自动结算）
```

### 规则

| 规则 | 说明 |
|------|------|
| 人数 | 1-8 人 |
| 赌注 | 最低 20，其他玩家需 ≥ 发起者的 1/2 |
| Blackjack | 起手 2 张 21 点，庄家非 BJ 时 1.5 倍赔付 |
| 爆牌 | >21 点自动停牌，输掉赌注 |
| 平局 | 退还本金 |
| 庄家爆牌 | 所有未爆牌玩家 1:1 胜出 |
| 超时 | 90s 无操作自动结算 |

### 牌面符号

♠ 黑桃  ♥ 红心  ♦ 方块  ♣ 梅花  
A=1或11  J/Q/K=10  2-10=面值

## 4. 俄罗斯轮盘

**1v1 左轮对决，金币下注。7 槽弹仓，1-6 颗子弹。**

```
/game start 俄罗斯轮盘 200     ← 发起对决，赌注 200
3                               ← 装填 3 颗子弹
接受对决                         ← 对手加入（双方各扣 200）
开枪                             ← 轮流扣扳机
```

### 规则

| 规则 | 说明 |
|------|------|
| 人数 | 2 人 |
| 弹仓 | 7 槽，子弹随机排列 |
| 开枪顺序 | 装弹者先开枪，之后轮流 |
| 赌注 | 双方等额，赢者通吃 |
| 超时 | 30s 无操作自动结算（判超时者负） |
| 取消 | `/game stop` 全额退还双方 |

存活概率每枪后实时更新（如"下一枪存活概率：50.0%"）。

## 5. 牛牛大作战

**持久化养成 RPG。牛牛永久存在，长度跨群共享。**

### 5.1 入门

| 命令 | 说明 |
|------|------|
| `注册牛牛` | 创建你的牛牛，随机初始长度 |
| `注销牛牛` | 删除牛牛（花费 500 金币） |

注册后你获得一个随机长度（可为负数，负数 = 深度/女孩子状态）。

### 5.2 日常操作

| 命令 | 说明 |
|------|------|
| `打胶` | 对自己的牛牛进行操作，结果随机（CD 180s） |
| `击剑 @某人` | 和对方对战，影响双方长度（CD 180s） |
| `我的牛牛` | 查看当前长度、排名、评论、最后打胶时间 |
| `我的牛牛战绩 [N]` | 查看最近操作记录（默认 10 条） |

### 5.3 排行

牛牛提供四种排行视角：

| 命令 | 说明 |
|------|------|
| `牛牛总排行 [N]` | 自然数值排行（有符号排序，正数在前负数在后） |
| `牛牛绝对值排行 [N]` | 绝对值排行（最长和最深都能排前列） |
| `牛牛长度排行 [N]` | 正数群体排行（仅 length > 0 的用户） |
| `牛牛深度排行 [N]` | 负数群体排行（仅 length < 0 的用户） |
| `牛牛长度总排行 [N]` | 全局正数排行（跨群） |
| `牛牛深度总排行 [N]` | 全局负数排行（跨群） |
| `牛牛绝对值总排行 [N]` | 全局绝对值排行（跨群） |

默认显示前 10 名，可指定 N（最大 50）。  
`我的牛牛` 命令会同时显示总排行、深度排行（负数用户）和绝对值排行的名次。

### 5.4 长度区间与评价

| 长度 | 评价 |
|------|------|
| >100 | 牛牛之王 |
| 50~100 | 惊世骇俗！牛头人 |
| 25~50 | 已经突破天际了嘛 |
| 10~25 | 已经很长了呢 |
| 0~10 | 细狗 / 蚕宝宝 |
| 0~-10 | 加油加油！我看好你哦 |
| -10~-25 | 你已经是一名女孩子了呢 |
| -25~-50 | 这名女生身体很健康 |
| -50~-100 | WOW，真的凹进去了好多呢 |
| <-100 | 哇哦！魅魔！ |

### 5.5 打胶事件

打胶时会随机触发不同事件：

| 事件 | 权重 | 效果 |
|------|------|------|
| 普通 | 60% | 长度正常增减 |
| 萎缩 | 10% | 长度直接减半 |
| 被抓 | 10% | 小黑屋 180s（禁止打胶） |
| 特殊加成 | 5% | 1.1 倍系数加成 |
| 急速惩罚 | 15% | 连续打胶时效果削弱 |

### 5.6 击剑机制

- 击剑胜率基于双方长度比值计算（差距越大，长者胜率越高）
- 胜者从败者身上夺取长度（差值 × 0.3，含平衡系数）
- 被击剑者有 300s 保护期，期间不可再次被击
