# AI 工具发现说明

这是一份给群友看的说明。你不需要配置它，只要知道机器人有时会先找工具，再回答问题。

---

## 1. 什么是工具

QuickQuip 的 AI 回复不只会聊天，也能在需要时调用工具，例如：

- 查群友身份和别名
- 查已保存的长期记忆
- 联网搜索
- 查看群状态
- 调用管理员接入的外部 MCP 能力

普通闲聊不一定会用工具。只有当问题确实需要外部信息或群内资料时，AI 才会尝试调用。

---

## 2. 为什么会出现“先找工具”

如果管理员接入了很多外部工具，机器人不会把所有工具说明都塞进每次 AI 请求。这样可以减少无关信息，让模型更专注当前问题。

这时 AI 可能先调用 `tool_search` 查找合适工具，然后再用找到的工具完成回答。如果它觉得工具存在但搜索没有命中，也可能调用 `tool_list` 查看工具组或工具名，再加载具体工具。这个过程通常不会要求你额外操作，只是回复可能多等一轮。

---

## 3. 怎么提问更容易命中工具

可以直接说清楚你想要的能力：

```text
/ai 帮我查一下这个 GitHub 仓库最近有哪些 PR
```

```text
/ai 搜一下最近关于某个版本的公告
```

```text
/ai 查查群里有没有关于阿桃喜欢什么的记忆
```

如果你知道管理员接入了某类外部工具，也可以把工具来源说出来：

```text
/ai 用 GitHub 工具查一下这个项目的 issue
```

---

## 4. 常见情况

### 回答说没有找到工具

这通常表示当前机器人没有启用对应能力，或者你的描述太模糊。可以换个更具体的说法，例如把“查一下那个东西”改成“用 GitHub 查仓库 issue”。

如果你知道工具来源，也可以说“列一下 GitHub 工具再找 PR 相关的那个”，机器人会更容易走 `tool_list` 兜底。

### 回答说工具结果不足

这表示工具被找到了，但返回的信息不够完整。AI 不会在工具结果不足时强行编造。

### 普通聊天会受影响吗

不会。工具发现只影响需要工具的 AI 回复，不影响复读、彩蛋、接龙等规则功能。
