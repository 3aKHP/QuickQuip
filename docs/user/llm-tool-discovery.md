# AI 工具发现说明

QuickQuip 的 AI 在回答前，可能先查找可用的工具再作答。本文介绍可以使用的能力，以及怎样提问更容易找到合适的工具。

---

## 1. 什么是工具

部署者启用工具调用后，AI 可以借助工具完成这些任务：

- 查群友身份和别名
- 查已保存的长期记忆
- 联网搜索
- 查看群状态
- 画一张矢量图（梗图、图表等，管理员开启后可用）
- 调用管理员接入的外部 MCP 能力

AI 根据问题选择要调用的工具。

---

## 2. 为什么会出现“先找工具”

启用工具发现后，机器人每次先向 AI 提供一部分工具说明。遇到需要其他能力的问题时，AI 会先搜索工具，必要时查看工具分类与名称，再使用找到的工具。这些步骤由机器人完成，回复可能多等一轮。

---

## 3. 怎么提问更容易命中工具

说清任务、查询对象和范围，例如：

- `/ai 帮我查看 https://github.com/3aKHP/QuickQuip 最近一周有哪些 PR`
- `/ai 搜一下 Python 3.13 的官方发布公告`
- `/ai 查查群里有没有关于阿桃喜欢什么的记忆`（将阿桃换成要查询的群友）

管理员已接入 GitHub 工具时，也可指定来源：`/ai 用 GitHub 工具列出 3aKHP/QuickQuip 当前仍开放的 issue`。

---

## 4. 常见情况

**提示没有找到工具**：通常是当前机器人没有启用对应能力，或者描述太模糊。换个更具体的说法，例如“用 GitHub 查 3aKHP/QuickQuip 当前开放的 issue”；知道工具来源时也可以说“列一下 GitHub 工具再找 PR 相关的那个”，帮助机器人找到对应能力。

**提示工具结果不足**：工具返回的信息不够完整。补充仓库名、日期范围或查询对象，帮助 AI 缩小查询范围。

**回复多等了一会儿**：查找和调用工具会增加处理时间；复读、彩蛋、接龙等规则回复按各自规则运行。
