# 新三国梗触发指南

这是一份给群友看的说明，介绍机器人内置的《新三国》电视剧梗是怎么触发的。

---

## 直接触发（说了就回）

下面这些梗只要消息里出现对应的词，机器人就会接话。

| 你说的 | 机器人回 |
|---|---|
| 你走了 | 我们吃什么 |
| 吃什么 | 是啊，吃什么 |
| 永恒的问题 | 是啊 |
| 三军听令 | 战至最后一刻 |
| ……最后一刻 | 战至最后一刻，自刎归天！ |
| 扎聋我自己的耳朵 / 议论孔明先生 | 我再听到你们议论孔明先生，我就扎聋我自己的耳朵 |
| 死不可怕 | 死是凉爽的夏夜 |
| 凉爽的夏夜 | 可供人无忧的安眠 |
| 不是 XX 害了你 | 不是 XX 害了你，是这乱世害了你啊 |
| 龙 / 聋 | 龙/聋，可是帝王之征啊 |
| 还活着吗 | 生死不明 |
| 生死不明 | 那就是亖了 |
| 蛐蛐儿 / 有情有义 / 我在想 | 我在想我的那些个蛐蛐儿，它们个个有情有义 |
| 恭喜 XX 可以称帝/撑地了 | 恭喜 XX 可以称帝/撑地了 |
| 当浮一大白 | 当浮一大白 |
| 得好啊 | 当浮一大白 |
| 我是不会客气的 | 来人 |
| 来人 | 换大盏 |

## 需要上下文才触发

这几条梗比较讲究时机，机器人会看最近几条聊天记录来判断语境是否合适。

### 竟然不许！？

**触发词**：消息里含有“竟然、不许、不行、拒了、没批、不准、不给过”之一

**条件**：最近 5 条消息里有人提到过请假、休息、调休、申请、审批、报备、出去、离开等词

**回复**：竟然不许！？

> 典型场景：有人说“我想请假”，然后有人说“不行”——机器人就会接这句。

---

### 胜兵必骄，骄兵必败……

**触发词**：消息里含有“胜兵必骄、骄兵必败、败兵必哀、哀兵必胜”之一

**条件**：最近 5 条消息里有人提到过胜、败、骄、哀、兵、心态、膨胀、谦虚等词

**回复**：胜兵必骄，骄兵必败，败兵必哀，哀兵必胜，胜兵必骄……

---

### 天意，天意啊

**触发词**：消息里含有“天意、命中注定、没办法、上天的安排”之一

**条件**：最近 8 条消息里有人提到过天意、命运、注定、老天、没辙、没办法等词

**回复**：天意，天意啊

---

### 只要曹孟德一息尚存……

**触发词**：消息里含有“一息尚存、还没死、活着、战无不胜”之一

**条件**：最近 6 条消息里有人提到过曹操、曹孟德、逆天、顽强、硬、死不了等词

**回复**：只要曹孟德一息尚存，他就战无不胜！

## 需要 AI 判断才触发

这几条梗的语境比较微妙，机器人会用 AI 快速判断一下当前聊天是否适合接这个梗，判断超时或不确定时不会触发。

### 好啊，他过江我也过江

**触发词**：消息里含有“好啊”

**AI 判断**：当前语境是否在说“他做某事，我也要跟着做”（类似“他过江我也过江”的跟风语境）

**回复**：好啊，他过江我也过江

---

### 徐州城不愧为中原第一雄关

**触发词**：消息里含有“真乃第一 XX”或“实乃第一 XX”

**AI 判断**：是否在用夸张语气称赞某事物是“第一 XX”，适合接这句台词

**回复**：徐州城不愧为中原第一雄关

---

### 一把叫仁之剑，一把叫义之剑

**触发词**：消息里含有“我有两个/两把/两件……”之类的表达

**AI 判断**：语境是否适合接这句台词

**回复**：一把叫仁之剑，一把叫义之剑

---

## 限流说明

所有新三国梗共用同一个限流桶，每分钟全群最多触发 12 次，同一个人最多触发 6 次。触发太频繁时机器人会暂时沉默，过一会儿就好了。
