# ADR-0018：将 MCP 结果归一化为受控内部内容

- 记录日期：2026-10-23
- 原始决策日期：2026-08-08；文本资源交付于 2026-09-11 扩展

## 背景

MCP 工具可以返回文字、图片、资源及其他内容。将未知结果原样转成 JSON 文本，会让 base64、资源标识和未支持内容进入日志或模型请求；不同 provider 也需要各自的多模态格式。

工具链需要统一的内部结果，以及每种内容进入模型前的校验和省略规则。

## 决定

MCP 层先将外部结果归一化为受控的内部类型，再交给共用工具链。可见文本按既有规则组合；未支持或无效的内容提供有限诊断。provider 适配器消费内部内容，并完成自己的协议序列化。

图片严格解码并校验格式、大小和 MIME，验证后的字节在当前工具循环中使用。视觉模型接收支持的图片表达，非视觉模型使用已配置的转述能力；工具错误、内容拦截或转述失败按相应规则省略图片。

## 方案与理由

raw JSON 回退虽然能够展示未知结果，也会绕过类型化内容的体积和交付约束。先建立归一化边界，再逐项扩展支持，可以让协议内容和模型能力在统一工具链中衔接。

2026-09-11 的扩展允许内联文本资源按文本 MIME 与长度上限进入工具文本管线。二进制 blob、音频、链接等继续按支持范围处理；资源地址不触发自动下载，完整 URI 不随资源正文渲染。

## 影响

新 MCP 内容类型需要明确校验、预算、错误和交付行为，避免通过未知内容回退隐式放行。图片用于后续模型推理，QQ 媒体交付由发送能力单独承担。

业务记录按自身保留政策处理结果，原始 HTTP Trace 作为独立诊断留档，启用时可能包含实际多模态请求。类型归一化与记录保留分别维护。
