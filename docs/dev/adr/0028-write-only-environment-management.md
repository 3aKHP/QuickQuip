# ADR-0028：环境变量只写管理与运行时凭据快照

- 决策日期：2026-11-09
- 记录日期：2026-11-09

## 背景

管理员需要通过 Web Admin 轮换 Provider 凭据、创建新渠道密钥及维护普通环境参数。根 `.env` 是持久化来源，Docker 的启动环境不能随文件修改自动更新。现有 LLM 发布流程已为任务固定配置版本。

## 决定

环境管理接口返回名称和状态，接收完整新值，不返回已有值。根 `.env` 采用版本检查、配置锁、私有恢复日志和原子替换；其他配置写入入口识别未完成的环境事务。

源码直接访问根文件。Docker 由独立 agent 挂载部署根，通过两个私有 Socket 区分读取与管理能力；Bot 仅获得读取能力，Web 获得管理能力，agent 不执行任意命令或 Docker 操作。

凭据以进程内不可变快照加载，任务固定其开始时的快照。认证 Header 保留变量模板，在创建客户端时按同一快照展开。凭据轮换独立于 LLM 配置发布，启动参数保持待重启。

源码启动、运行时和配置工具采用共享 dotenv 解析。管理接口写入的字面值带格式标记，并对 Docker 的美元符号插值进行转义，保证重启和配置回流后的含义一致。

## 候选与理由

容器重新创建能更新启动环境，适用于启动参数；凭据轮换采用应用快照以保持服务连续。共享全权限控制通道会扩大 Bot 的写入权限，分离通道可保持其只读配置边界。

## 影响

首次接入 Docker 需要更新编排并创建 agent 与通信卷。环境状态分别记录持久化版本、进程启动基线和当前快照确认。Trace 保留原始报文诊断契约。
