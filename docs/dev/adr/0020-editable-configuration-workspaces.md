# ADR-0020：以持久 TOML 工作副本编辑配置包

- 记录日期：2026-10-24
- 原始决策日期：2026-10-24

## 背景

配置由 SQLite 管理，部署者通过 Web Admin 和本地工具修改配置。人工审阅和委托 LLM 编辑需要可拆分文本，也需要在数据库变化后保留注释和工作中的修改。

## 决定

在统一配置包上提供版本化 TOML 工作副本。CLI 负责初始化、校验、计划、组装、刷新和恢复。工作副本维护文本与基线，组装生成草稿，发布和服务器同步沿用已有流程。

空值、大整数及保留键对象使用无歧义编码。清单管理对象集合与顺序，资产保持原字节。冲突单元继续为整份 LLM 文档及单个资产。

## 方案与理由

一次性导出提供编辑入口，持续工作副本还能保留人工解释与未组装修改。数据库维护配置语义，工作副本维护文本表达。整文档冲突规则复用已经接受的引用和顺序校验，更细对象合并另行设计。

组装复用端点事务，增加独立本地完成入口，保持工作副本和服务器同步的基线职责。跨文件与数据库写入通过日志和恢复副本处理。

## 影响

新增 tomlkit 依赖和工作副本格式版本。安装文件须停止消费者，目标资产须支持当前发布启动。外部修改使计划失效或阻止恢复覆盖。
